1. What CameraEmulator does

CameraEmulator adds a webcam named CameraEmulator to Windows. Any program that uses a webcam can select it, and in particular the Android Emulator, which can then show it as the phone's camera. This lets you test camera features of an Android app, such as QR code or barcode scanning, without a real camera.

The camera can show:

  • an image of your choice (PNG, JPEG, BMP, GIF, TIFF), for example a QR code;
  • a zone of your screen, live at 30 frames per second, for example a QR code displayed in a browser or another program;
  • a default image with the CameraEmulator logo when nothing else is selected.

Everything is controlled from an icon in the notification area (the system tray). A command-line tool is also available for scripts.

2. Installation

Requirements

  • Windows 11 (virtual cameras are not available on Windows 10).
  • The Android SDK Emulator, if you want to use the camera in Android.
  • Administrator rights, once, for step 2 below.

Steps

  1. Extract all the files of the CameraEmulator zip file to a folder, for example your Downloads folder. Right-click the zip file, then Extract All…
  2. In the extracted folder, double-click Install.bat, press a key, and accept the administrator prompt.

The installer:

  • copies the program to C:\Program Files\CameraEmulator and registers the camera component;
  • creates the camera, permanently, for your Windows account;
  • adds CameraEmulator to the Start menu;
  • starts the tray app: the camera icon appears in the notification area.

You can delete the extracted folder afterwards. To upgrade to a new version, run the new Install.bat: it replaces the program files and keeps your image and settings.

Installing manually. If you don't use Install.bat, copy the files to a folder outside your user profile, such as C:\Tools\CameraEmulator. The Windows camera service can't read folders like Desktop, Documents or Downloads. Then register the camera component from a Command Prompt as administrator: 
regsvr32 "C:\Tools\CameraEmulator\CameraEmulatorSource.dll"
Windows loads the component from that folder: if you move the files, register them again.

3. Quick start

  1. Start CameraEmulatorTray.exe.
  2. Click the camera icon in the notification area. Windows 11 may hide new icons behind the ^ arrow: drag the icon onto the taskbar to keep it visible.
  3. Check Keep the camera when this app is closed, so that the camera is always present, even after a reboot (recommended for the Android Emulator).
  4. Optionally check Start with Windows.
  5. Choose what the camera shows: Choose image…, or Start broadcast to show a zone of the screen.
  6. Configure your Android virtual device to use the CameraEmulator webcam (next section).

4. Using it in the Android Emulator

Find the name of the webcam

The Android Emulator names webcams webcam0, webcam1, and so on. To see which one is CameraEmulator, run this in a command prompt (adjust the SDK path if needed):

"%LOCALAPPDATA%\Android\Sdk\emulator\emulator.exe" -webcam-list

Look for the line Camera 'CameraEmulator (…)' can be specified by label as 'webcam1'.

The numbering follows the list of cameras present on the PC. It can change when you plug in or remove another camera. Check it again if the wrong camera shows up.

Select it as the back camera

In Android Studio: Device Manager → Edit (pencil icon) on your virtual device → Advanced Settings → Back camera → Webcam1 (the name found above).

Or in the device's configuration file, while the emulator is closed: %USERPROFILE%\.android\avd\<device name>.avd\config.ini

hw.camera.back=webcam1

Or for one session only, on the command line:

emulator -avd <device name> -camera-back webcam1

Then open the camera app, or your own app, in the emulated phone.

5. Showing an image

Click the tray icon → Choose image… and select a picture. The camera switches to it within about a second, even if an app is already using the camera. The image is fitted into the camera picture without distortion; the remaining space is black, and transparent areas also show as black.

To go back to the built-in picture, choose Use default image.

The image you choose is copied to C:\ProgramData\CameraEmulator\image.png, so you can move or delete the original file afterwards.

6. Broadcasting a zone of the screen

Instead of a fixed image, the camera can show a live zone of your screen. For example, open a QR code in a browser, place the zone over it, and the Android app sees it as if you were holding a phone in front of it.

Start

  • Start broadcast (first item of the tray menu), or press Ctrl+Alt+C anywhere: starts with the remembered zone. By default this is a 300 × 300 zone, well suited to QR codes, centered on the screen where the mouse is.
  • Choose zone and start: pick another zone, which becomes the remembered one (shown with a check mark):
    • Select zone…: the screen darkens; drag a rectangle with the mouse. Press Esc or right-click to cancel.
    • Last zone: the exact position and size used last time.
    • 300 × 300, 640 × 480, 800 × 600, 1280 × 720: a zone of that size, centered on the screen where the mouse is.

While broadcasting

  • A red frame shows the zone. It is not part of the picture.
  • Move the zone by dragging the red frame or its drag to move tab. The camera follows immediately.
  • You can still click and type inside the zone: the frame doesn't block it.
  • The tray icon shows a red dot.

Stop

Stop broadcast in the tray menu, or press Ctrl+Alt+X anywhere. The camera goes back to the image (or the default image) within two seconds.

Zones are measured in screen pixels. On a display scaled to 125% or 150%, a 300 × 300 zone looks smaller than 300 "Windows" units: that's expected.

7. Layouts

The Layout submenu controls how the picture is placed in the camera image:

LayoutUse it for
Android emulator (portrait)
(default)		 The Android Emulator with a phone in portrait orientation. The emulator only keeps the left part of webcam images when it rotates them for a portrait phone; this layout places the picture exactly in that part, so the whole picture shows up in Android.
Fit (desktop apps) Windows programs (the Camera app, Teams, browsers…) and the Android Emulator in landscape orientation. The picture is centered in the camera image.

If the picture looks squeezed to the left in a Windows program, switch to Fit. If it looks cut off or zoomed in the Android Emulator, switch to Android emulator.

9. Command line reference

CameraEmulator.exe provides the same features for scripts and batch files. Run it without valid arguments to see a short usage summary.

CommandEffect
CameraEmulator.exe --installInstall the camera permanently (no administrator rights needed).
CameraEmulator.exe --uninstallRemove the installed camera.
CameraEmulator.exe image.pngShow this image. If the camera is not installed, the program keeps it available until you press Ctrl+C.
CameraEmulator.exe --update image.pngOnly change the image, then exit.
CameraEmulator.exe --update --default-imageGo back to the default image.
CameraEmulator.exe --layout android
CameraEmulator.exe --layout fit		 Change the layout.
CameraEmulator.exe --screenDrag a rectangle, then broadcast it.
CameraEmulator.exe --screen 300x300Broadcast a 300 × 300 zone centered on the screen where the mouse is.
CameraEmulator.exe --screen 100,200,800,600Broadcast the zone at x = 100, y = 200, 800 wide and 600 high.
--stop-key ctrl+shift+f12Added to a --screen command: another stop shortcut for this run.

A screen broadcast started from the command line stops with Ctrl+Alt+X or Ctrl+C in the console. When it stops, the program prints the last position, which you can reuse with --screen.

10. Settings file

Settings are stored in C:\ProgramData\CameraEmulator\settings.ini. Most are changed from the menu. The keyboard shortcuts can only be changed here, in the [screen] section:

[screen]
startKey=ctrl+alt+c
stopKey=ctrl+alt+x

A shortcut is a combination of ctrl, alt, shift and win, plus one letter, digit, or F1–F24, separated by +. At least one of ctrl, alt, shift or win is required. If startKey and stopKey are the same, that shortcut turns the broadcast on and off. Restart the tray app after editing the file.

11. Troubleshooting

ProblemSolution
CameraEmulator doesn't appear in the list of webcams. Check that the tray app is running, or that Keep the camera when this app is closed is checked. Check that regsvr32 was run as administrator from the current folder (see Installation). In Settings → Privacy & security → Camera, allow camera access, including for desktop apps.
A notification says the camera could not start. The camera component is not registered, or was moved: run regsvr32 again as administrator.
The Android camera app crashes, or shows another camera. The virtual device points to the wrong webcam. Run emulator -webcam-list again and fix hw.camera.back (see section 4).
"Can't connect to the camera" right after the emulator starts. The emulator resumed from a saved state (quick boot) with the camera app already open. Close the camera app and open it again, or start the emulator with -no-snapshot-load.
The picture is cut off or zoomed in Android. Use the Android emulator (portrait) layout. If the phone is in landscape orientation, use Fit.
The picture is squeezed to the left in a Windows program. Use the Fit (desktop apps) layout.
A shortcut doesn't work. Another program already uses it; the tray app shows a notification at startup. Choose another shortcut in settings.ini, or use the menu.
The tray icon is not visible. Click the ^ arrow in the taskbar, then drag the icon onto the taskbar.
"CameraEmulator is already running". Only one tray app can run at a time. Look for its icon behind the ^ arrow.

For more details, the log files tray.log and source.log are in C:\ProgramData\CameraEmulator (Open settings folder).

12. Uninstalling

Run Uninstall.bat in C:\Program Files\CameraEmulator, confirm, and accept the administrator prompt. It closes the tray app and removes the camera, the startup entry, the Start menu shortcut, the camera component and the program folder. It asks whether to also delete your image and settings (C:\ProgramData\CameraEmulator).

If you installed manually: in the tray menu, uncheck Start with Windows and Keep the camera when this app is closed, choose Exit, run regsvr32 /u "C:\Tools\CameraEmulator\CameraEmulatorSource.dll" as administrator, then delete the program folder and C:\ProgramData\CameraEmulator.
