CameraEmulator - virtual webcam for the Android Emulator (Windows 11)
=====================================================================

Installation
  1. Extract all the files of this zip to a folder.
  2. Double-click Install.bat and accept the administrator prompt.
     The program is installed in "C:\Program Files\CameraEmulator", the camera is
     created, and the CameraEmulator icon appears in the notification area.

Using it
  Click the CameraEmulator icon in the notification area to choose an image or to
  broadcast a zone of the screen. In the Android Emulator, select the webcam named
  CameraEmulator as the back camera.

  The full user guide is CameraEmulator-Help.html (also "Help" in the tray menu).

Uninstallation
  Run "C:\Program Files\CameraEmulator\Uninstall.bat".
